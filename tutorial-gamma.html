INTRODUCCIÓN

¿Qué es Gamma?

Gamma es una plataforma de inteligencia artificial que permite crear presentaciones, documentos y páginas web a partir de instrucciones escritas.

En lugar de diseñar cada diapositiva manualmente, puedes escribir el tema que deseas explicar. Gamma propone una estructura inicial con textos y elementos visuales que puedes modificar.

TUTORIAL PRÁCTICO

Crea tu primera presentación

Sigue estos pasos para generar una presentación con Gamma.

01

Entra a Gamma

Visita gamma.app y crea una cuenta o inicia sesión. Puedes explorar las opciones disponibles en su plan gratuito.

02

Crea un nuevo proyecto

Busca la opción para crear contenido con IA. Selecciona una presentación y elige generar contenido a partir de una idea. Los nombres de las opciones pueden cambiar según la versión de Gamma.

03

Escribe tu tema

Describe de qué tratará la presentación, para quién está dirigida y qué información deseas incluir.

04

Personaliza la estructura

Revisa el esquema propuesto, ajusta las secciones y selecciona un estilo visual adecuado para tu presentación.

05

Genera y revisa las diapositivas

Deja que Gamma genere el contenido inicial. Después revisa los textos, comprueba los datos y modifica las imágenes o secciones que necesites.

06

Comparte tu presentación

Utiliza las opciones disponibles para compartir tu trabajo mediante un enlace o exportarlo en un formato compatible, según tu plan.

EJEMPLO PRÁCTICO

Prueba este prompt en Gamma

Imagina que necesitas preparar una exposición sobre inteligencia artificial. Puedes utilizar una instrucción como esta:

Ejemplo de prompt

Crea una presentación de 8 diapositivas sobre la inteligencia artificial para estudiantes. Incluye una introducción, qué es la IA, cómo funciona de forma sencilla, ejemplos cotidianos, ventajas, riesgos, recomendaciones para utilizarla responsablemente y una conclusión. Usa un lenguaje claro, títulos cortos y ejemplos fáciles de comprender.

PREGUNTAS FRECUENTES

Preguntas sobre Gamma

¿Gamma es gratis?

Gamma ofrece un plan gratuito con límites de uso y funcionalidades. También dispone de planes de pago.

¿Puedo editar las presentaciones?

Sí. Puedes modificar el contenido, reorganizar las secciones y personalizar diferentes elementos del diseño.

¿Puedo exportar a PowerPoint?

Gamma ofrece opciones de exportación, entre ellas PowerPoint. Algunas funciones o limitaciones dependen del plan.

¿Gamma hace todo automáticamente?

Gamma puede generar un borrador inicial, pero es importante revisar los datos, corregir posibles errores y adaptar el resultado a tus necesidades.
